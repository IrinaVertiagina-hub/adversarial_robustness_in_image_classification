# Adversarial Robustness in Image Classification

Exploring how adversarial attacks can compromise image classification models and how to defend against them.


## Demo

[Live Streamlit App](https://adversarial-robustness-image-classification.streamlit.app/)
(the app might go into "sleep mode", please click "Wake it up".)

Upload any image and see how FGSM attack affects model predictions — and how adversarial training defends against it.

## Results

|                       | Clean Accuracy | Under PGD Attack (ε=0.1) |
| Baseline ResNet18     |         89.03% |                   3.90%  | 
| Adversarially Trained |         82.06% |                   63.37% |

## Attacks

**FGSM (Fast Gradient Sign Method)** — single-step attack. Adds a small perturbation in the direction of the gradient.

| Epsilon | Accuracy |
|---------|----------|
| 0.00    |   89.01% |
| 0.05    |   40.92% |
| 0.10    |   24.28% |
| 0.20    |   15.40% |
| 0.30    |   12.69% |

**PGD (Projected Gradient Descent)** — multi-step attack. Significantly stronger than FGSM.

| Epsilon | Steps | Accuracy |
|---------|-------|----------|
| 0.05    |    10 |   21.96% |
| 0.10    |    20 |    3.90% |
| 0.20    |    20 |    0.17% |

## Defense

**Adversarial Training** — model is trained on adversarial examples generated by PGD during training.

- Clean accuracy: 82.06% (trade-off: -7% vs baseline)
- Adversarial accuracy under PGD: 63.37% (vs 3.90% baseline)

## Stack

- **Model:** ResNet18
- **Dataset:** CIFAR-10
- **Attacks:** FGSM, PGD via Adversarial Robustness Toolbox
- **Experiment Tracking:** MLflow on DagsHub
- **Data Versioning:** DVC on DagsHub
- **Containerization:** Docker
- **CI/CD:** GitHub Actions
- **Demo:** Streamlit
